# Hakim Atek – personal website
Static site (HTML, CSS, JS; no build step). Upload everything to a repo named `<username>.github.io` and enable Pages (main / root).

- Banner: save the ESA/Webb image (esawebb.org/images/potm2505a, CC BY 4.0) as `assets/glimpse-banner.jpg`; keep the credit line.
- Portrait: `assets/hakim.jpg`. CV: `cv.pdf`.
- Project logos: official files in `assets/logos/` (glimpse, uncover, venus, euclid, moons, roman `.svg`) replace the placeholder emblems.
